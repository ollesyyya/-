Вариант 10. Реализуйте генерацию всех бинарных строк длины n.
Описание функции: Функция генерирует все возможные бинарные строки длины n с помощью рекурсивного алгоритма. На каждом шаге к текущей строке добавляется либо '0', либо '1', пока не будет достигнута нужная длина.
Пример работы для n=2:
Начало: "" (пустая строка)
Добавляем 0 → "0" → добавляем 0 → "00" 
                   → добавляем 1 → "01" 
Добавляем 1 → "1" → добавляем 0 → "10" 
                   → добавляем 1 → "11" 
Описание работы программы: Пользователь вводит длину бинарных строк n; Программа рекурсивно генерирует все комбинации из 0 и 1; Когда длина текущей строки достигает n, она добавляется в результат; Все сгенерированные строки выводятся на экран.
Временная сложность: O(n × 2ⁿ)
Обоснование: Алгоритм генерирует 2ⁿ бинарных строк (каждая позиция может быть 0 или 1), и для каждой строки выполняется O(n) операций для построения.

Контрольный вопрос 1: Что такое рекурсия и какие два обязательных компонента должна содержать рекурсивная функция?
Рекурсия — это техника программирования, при которой функция вызывает саму себя для решения задачи.
Каждая рекурсивная функция должна содержать:
1) Базовый случай — условие, при котором рекурсия останавливается
2) Рекурсивный переход — вызов функции с изменёнными параметрами, приближающими к базовому случаю
Эти два элемента работают вместе: рекурсивный переход дробит задачу на более простые части, а базовый случай обеспечивает завершение процесса.
